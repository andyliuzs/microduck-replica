# 27日版系统怎样获得新功能

这次交付的是 **2026.10.31 软件更新**，沿用 20261027 镜像已经具备的升级机制。已有卡更新软件即可，不需要重新烧录。原 20261027 镜像及其下载文件保持不变。

本页先随源码准备；具体下载、签名与验收记录在正式发行时补齐，不能把源码完成当成设备已经更新。

| 名称 | 管什么 |

## 已经使用27日版镜像

1. 保持主板联网。停止策略、语音监听、音乐、动作录放、舵机和标定会话，按页面的准备检查操作。
2. 打开原控制网页的 **设置 → 软件更新**，检查、下载并安装新软件包；不能联网时，上传完整的 `2026.10.31.software-update.tar`。
3. 等网页自动重连，核对软件版本。若页面提示配套驱动尚未更新，按该区域的提示扶稳、卸力并明确确认，完成第二阶段。
4. 等实际驱动检查通过，再使用手柄重新映射。网页出现新按钮不代表配套驱动已经安装；主程序原本已是 `.47` 的设备也可能仍需更新手柄程序。

已有升级入口的27版设备不要重新运行首次引导，也不要把 bootstrap 压缩包上传到网页。

如果没有软件更新入口，或服务仍从 `/home/radxa/studio-dev` 运行，需要由维护者经 SSH 做一次兼容性核对、备份及首次引导。引导安装升级服务、公钥和语音资源；之后使用同一个网页升级流程。

不通过准备检查时保留现状和具体原因，不伪造设备数量、停止状态或卸力确认，不用强行站起来解决升级问题。初次引导不是给所有27版用户重复执行的一步。

## 新功能在哪里

### 手柄按键重新映射／校准

进入手柄区域的 **重新映射／校准**：

1. 连接实体手柄，按页面要求让鸭子处于允许学习的停止状态。
2. 开始按键学习。点网页上的 A，再按实体手柄上希望作为 A 使用的按键；其余按钮同样操作。
3. 按提示完成摇杆两端行程并回中，可设置方向及死区，校准模拟或数字扳机。
4. 检查预览对应关系，命名保存，松开全部按键并让摇杆回中后再恢复控制。随后重新验证急停。

学习期间不执行手柄运动和语音动作。保存后网页显示、实际控制与 R3／Select 语音按键使用同一份映射。必需项未设置时不能保存；可以取消保留旧配置，也可以恢复该设备的默认识别。

配置按可识别设备保存。某些接收器把不同连接方式呈现为同一个设备，不能保证每种上游 USB／蓝牙方式都有独立身份。真实不同型号手柄仍需逐一验收。

### 摄像头原地放大

鸭子模型下方的摄像头卡片按实际横竖比例显示完整画面。**放大**扩大当前卡片，**还原**恢复原尺寸，操作不会跳到另一页或重新建立视频连接。

这只改变显示大小，不增加摄像头细节，也不修正曝光。保留当前摄像头来源设置；原本配置为测试画面的设备不会因为软件更新自动变成真实摄像头。硬件、接线和实际出图需分别确认。

### SSH 指引与音乐播放

设置中的 SSH 指引解释网页密码与主板 SSH 密码的区别，并提供可以交给 AI 工具使用的连接信息。连接说明不包含明文密码。

音乐播放器可添加、播放和删除用户自己的音乐文件，动作控制与播放独立。用户音乐、动作、网络、模型、标定及 API Key 不随程序版本树替换；发行包不包含维护者个人音频或歌曲。

## 回退与恢复

软件更新失败和配套驱动更新失败是两个事务，各自显示实际状态。驱动升级过程中出现中断时，先按当前页面的恢复流程处理，不删除保护文件后强行启动。

回到不支持映射的旧软件之前，需要先用新小助手完整恢复匹配的旧手柄程序和服务设置。不能只回退网页、继续让旧语音服务读取新手柄映射；兼容性保护会拒绝这种组合。

升级包的签名、冻结源码、精确二进制、原27升级器测试及实物验收边界将在发行验证记录中列出。没有实际安装并回读确认的设备，不能按软件包版本推断其已经具备新功能。
