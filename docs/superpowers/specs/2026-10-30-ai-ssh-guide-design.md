# AI 助手 SSH 连接指引

用户已确认入口、跳转和分步提示方案，要求实现并检查提示与布局。

## 行为与布局

- 总览仪表带之后、设置页标题之后提供紧凑的「让 AI 连接鸭子（SSH）」入口，跳到 `#/settings/ssh` 并滚动到连接指引；设置导航仍高亮。
- 指引复用现有 `/api/password`、`/api/ssh`，不自动开启 SSH，不改认证、系统服务或运动控制。
- 依次显示网页密码、SSH 系统密码、复制连接说明。网页密码保护浏览器控制；SSH 密码用于电脑终端／AI 助手登录 radxa 系统账号。分别保存、独立修改。确认输入仅用于核对，正常登录输一次。
- 已设网页密码时显示已设置并折叠修改表单；SSH 密码已开启或已有公钥时显示现有连接信息，无需重设。公钥管理放在展开区，保留旧功能。
- SSH 状态失败、服务未运行、无网页登录密码、操作失败时分别说明，提供重试，不把登记钥匙或开启密码等同于已经成功连接。
- 连接说明包含经校验的主板地址、账号、端口 22、登录命令及密码／公钥方式；仅在系统报告 SSH 运行且有登录方式时提供复制。密码不参与生成、复制或存储。HTTP 环境无法使用 Clipboard API 时提供可选择的文本。
- 桌面宽度沿用设置页，窄屏所有输入和按钮允许换行；保留可见焦点、表单标签、步骤状态。

## 验证边界

使用真实 Studio、隔离的假 robotd 和仅替换系统 SSH 边界的 helper fixture。浏览器验证入口跳转、两类密码的区别、密码确认、网页密码保存后进入下一步、SSH 开启／修改／失败／重试／已开启、公钥兼容、复制不包含密码、HTTP 复制失败的手工途径和 1440/390/320 像素布局。运行现有认证、SSH helper、钥匙及相关后端回归。测试不连接实体鸭子，不执行系统 SSH 修改，不启用运动，不发布升级包。
