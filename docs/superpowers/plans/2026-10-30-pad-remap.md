# Controller remapping implementation plan

**Goal:** Persist user-learned controller mappings and use the same mapping for display and real padd control.

**Architecture:** A new bounded local padd mapping control socket owns raw snapshots, persisted profiles and an authoritative output gate. Studio owns per-page learning UX and calls that socket; the web page never writes a profile without native acknowledgement.

**Tech Stack:** Rust/serde/evdev/padd, Python 3.13, Preact/htm, Node and headless Edge. Dedicated native and Studio worktrees.
